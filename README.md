# Instagram DM Export Joiner

This is a local, lightweight Python Flask application designed to join, sort, and view chunked chat export ZIP files generated by your Instagram DM exporter Chrome extension. It reads individual chunks, deduplicates overlapping records, arranges messages chronologically, isolates and streams media files, and serves them on a beautiful web interface.

## Core Features

- **Folder Auto-Scanning**: Scans your local `data/zips/` directory on startup and automatically parses and extracts any ZIP exports.
- **Drag-and-Drop Uploader**: Modern drag-and-drop uploading directly via the web dashboard.
- **Dynamic Caching**: Caches parsed ZIP metadata as JSON internally so subsequent loads are instantaneous.
- **Overlap Deduplication**: Detects overlapping messages across files and filters duplicates based on sender, time, date, and bubble body hashes.
- **Strict Chronological Ordering**: Integrates timestamps, relative chunk order, and original index positions to preserve perfect chronological flow—even for multiple messages sent in the same minute.
- **Interactive Search**: Client-side, debounced searching to locate and filter texts or senders instantly across tens of thousands of messages.
- **Lazy Load Scroll rendering**: Renders messages in scrolling batches of 500 nodes to keep rendering smooth and browser memory low for massive chat databases (50,000+ DMs).
- **Media Lightbox**: Full-screen modal to expand images and play video or audio records directly on the webpage.
- **Light & Dark Themes**: Sleek dark and light mode stylesheets matching modern web patterns.

## Running the Application

### 1. Ensure Dependencies
Your environment already has `flask` and `beautifulsoup4` installed.

### 2. Startup the Server
Open a terminal in the `joiner/` directory and run:

```powershell
python app.py
```

### 3. Access the Dashboard
Navigate to the following address in your web browser:
```text
http://127.0.0.1:5000
```

### 4. Load your Chats
- Put your exported chat ZIP files directly inside the `data/zips/` folder and refresh the page, OR
- Drag and drop the ZIP files onto the dashed card zone on the dashboard page.

Once uploaded or scanned, click **View Chat** to enjoy reading your complete, combined chat history.
